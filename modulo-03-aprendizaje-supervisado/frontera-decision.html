// el problema

Separar en vez de predecir un número

¿Este correo es spam o no? ¿Este préstamo se aprueba o se rechaza? Ya no queremos un número — queremos elegir entre categorías a partir de ejemplos ya etiquetados. Geométricamente, si representamos cada ejemplo como un punto en un plano (dos características, dos ejes), el trabajo del algoritmo es encontrar una frontera que separe los grupos lo mejor posible.

Aquí vas a entrenar un modelo lineal (regresión logística) que dibuja esa frontera como una línea recta — y también vas a intentar dibujarla tú mismo a mano, para comparar tu intuición contra lo que encuentra el algoritmo.

De una recta a una probabilidad

El modelo calcula un puntaje lineal a partir de las dos coordenadas de un punto (igual que la recta del demo anterior, pero con dos variables). Ese puntaje puede ser cualquier número, así que se pasa por la función logística (sigmoide), que lo "aplasta" a un valor entre 0 y 1 — una probabilidad de pertenecer a la clase B. El entrenamiento ajusta la recta (por descenso de gradiente, igual que antes, pero minimizando entropía cruzada en vez de error cuadrático) para que esas probabilidades se acerquen a las etiquetas reales.

Prueba el conjunto de datos "No separable (XOR)". Vas a ver que, entrenes lo que entrenes, la recta nunca logra separar bien los grupos — porque geométricamente no existe una línea recta que los separe. Un modelo lineal solo puede dibujar fronteras rectas. Superar esa limitación es exactamente uno de los motivos por los que existen las redes neuronales del Módulo 5.

Preguntas para el debate

  • ¿Lograste dibujar a mano una frontera con mejor precisión que el modelo entrenado? ¿En qué conjunto de datos fue más fácil o más difícil?
  • En el conjunto "con solapamiento", ¿puede algún modelo lineal lograr 100% de precisión? ¿Por qué no, y qué significa eso sobre los datos mismos?
  • ¿Por qué la función sigmoide, y no simplemente usar el puntaje lineal directamente como probabilidad?
  • ¿Qué otras dos características (features) del mundo real usarías para separar spam de no-spam? ¿Crees que una frontera recta bastaría?
