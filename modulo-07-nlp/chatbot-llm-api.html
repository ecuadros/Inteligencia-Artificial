// el problema

Un modelo de lenguaje grande no cabe en tu navegador

Todo lo que construiste hasta ahora corrió con datos y modelos diminutos, enteramente en tu navegador. Un modelo como el que responde este chat tiene miles de millones de parámetros — no hay forma de descargarlo ni de correrlo en una laptop de curso. La única opción es llamar a un servidor remoto que ya tiene el modelo cargado, mandarle tu mensaje, y esperar la respuesta.

Eso convierte a este demo en el único de todo el curso con una arquitectura cliente-servidor real — y es exactamente lo que CLAUDE.md de este sitio dice que evitemos en todos los demás ("no backend, todo corre en el navegador"). Aquí vas a ver, en vivo, por qué esa regla existe y qué se gana al romperla.

Tu clave, tu responsabilidad: este demo no trae ninguna clave de API incluida. Necesitas pegar la tuya propia (de Anthropic, OpenAI, o un servidor compatible como Ollama local) para que funcione. Tu clave nunca se guarda ni se envía a ningún servidor de este sitio — vive solo en la memoria de esta pestaña y se pierde al recargar. Aun así, usa una clave con límite de gasto bajo y nunca la escribas en una computadora que no sea tuya.

  // cómo funciona
  
Un fetch, un JSON, una respuesta

  

    Cada vez que envías un mensaje, esta página arma una petición HTTP con tu clave, el historial de la
    conversación, la instrucción de sistema y la temperatura, y la manda directo desde tu navegador al
    servidor del proveedor (usa "Mostrar solicitud/respuesta cruda" para ver exactamente ese JSON). El
    servidor corre el modelo — la parte que no cabe en tu laptop — y devuelve el texto generado.
  

  

    La temperatura controla cuánto "arriesga" el modelo al elegir la siguiente palabra:
    baja (cerca de 0) lo hace repetir siempre la opción más probable, dando respuestas más predecibles;
    alta (cerca de 1) le permite elegir palabras menos obvias, dando respuestas más variadas — y a veces
    más erráticas.
  

  

    Por qué casi ningún demo real de IA es "sin backend": ahora que viste la excepción,
    la regla tiene más sentido. Los modelos de los módulos anteriores eran chicos a propósito, para que
    cupieran en tu navegador. Un producto real con un modelo de este tamaño necesita un servidor — y ese
    servidor es también donde se protege la clave de API, se controla el gasto, y se agregan filtros de
    seguridad antes de que la respuesta llegue al usuario. Nada de eso existe en este demo educativo: por
    eso tu clave vive solo en tu navegador y por eso te pedimos usar una con límite de gasto bajo.
