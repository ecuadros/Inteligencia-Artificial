El problema Práctica Cómo funciona Debate
// el problema

¿Cómo se le enseña a una red a "dibujar de la nada"?

Los modelos que generan imágenes a partir de texto (Stable Diffusion, Midjourney, DALL·E) no dibujan trazo por trazo como una persona. Empiezan con ruido puro — como la nieve de una televisión sin señal — y lo van "limpiando" paso a paso hasta que aparece una imagen coherente.

La idea clave, y la razón por la que esto es entrenable, es que resulta mucho más fácil enseñarle a una red a hacer una tarea pequeña y repetible ("dado este ruido, adivina qué parte es ruido y quítala un poco") que enseñarle a generar una imagen completa de un solo salto.

// cómo funciona

Ida: mezclar con ruido. Vuelta: adivinar qué era ruido

El proceso "hacia adelante" tiene una fórmula cerrada y simple: en el paso t, la imagen ruidosa es x_t = √(ᾱ_t)·x₀ + √(1−ᾱ_t)·ruido, donde ᾱ_t baja suavemente de 1 (nada de ruido) a casi 0 (ruido puro) a medida que t avanza. No hace falta ninguna red neuronal para esta dirección — es solo álgebra.

La dirección inversa es la difícil: dado x_t (ruidoso), predecir qué ruido se le agregó para poder restarlo. Ahí es donde entrena una red neuronal real — ve millones de pares (imagen ruidosa, ruido que se le agregó) y aprende a estimar el ruido en cualquier imagen nueva.

La trampa de este demo: entrenar esa red de verdad está fuera del alcance de un navegador. Aquí "Generar" no adivina el ruido — hace trampa y usa la fórmula hacia adelante en reversa, porque ya conocemos tu dibujo original. Un modelo real nunca ve la imagen final durante la generación; solo tiene su propia predicción del ruido, paso a paso, entrenada de antemano sobre millones de imágenes reales.

Preguntas para el debate

  • ¿Por qué crees que es más fácil entrenar una red para "quitar un poco de ruido" que para "generar la imagen completa de un tirón"?
  • Si la reconstrucción real no puede ver la imagen original (a diferencia de este demo), ¿de dónde saca la variedad para generar imágenes distintas cada vez a partir del mismo texto?
  • ¿Qué relación ves entre "predecir el ruido en cada paso" aquí y "predecir el siguiente token" en un modelo de lenguaje como el del demo del chatbot?
  • Un modelo de difusión entrenado sobre millones de imágenes de internet puede reproducir sesgos de esos datos (por ejemplo, asociar ciertas profesiones con un género). ¿Qué relación tiene esto con el demo de sesgo algorítmico de esta misma sección?
